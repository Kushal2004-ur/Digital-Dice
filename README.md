# 🎲 Digital Dice

A simple and interactive **Digital Dice** web application built using **HTML, CSS, and JavaScript**.

Click the **Roll** button to generate a random number between **1 and 6**, just like rolling a physical dice.

---

## 📌 Project Overview

Digital Dice is a beginner-friendly JavaScript project created to practice:

- HTML structure
- CSS styling and layout
- JavaScript DOM manipulation
- Event handling
- Random number generation
- Connecting HTML, CSS, and JavaScript

The application generates a random dice value whenever the user clicks the **Roll** button.

---

## 🚀 Features

- 🎲 Generates a random number from **1 to 6**
- 🖱️ Interactive **Roll** button
- 🔄 Generates a new value on every click
- 🎨 Clean and simple user interface
- 📱 Responsive viewport setup
- ✨ Button hover effect
- ⚡ Instant result without page reload

---

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| **HTML5** | Creates the structure of the application |
| **CSS3** | Handles styling, layout, colors, shadows, and hover effects |
| **JavaScript** | Generates random dice values and updates the page |
