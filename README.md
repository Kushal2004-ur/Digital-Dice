# Digital Dice

A simple interactive **Digital Dice** application built using **HTML, CSS, and JavaScript**.

This project simulates rolling a dice and displays a randomly generated dice value. It was created to practice JavaScript **random number generation, DOM manipulation, event handling, and conditional logic**.

---

## 🚀 Features

- 🎲 Simulates a six-sided dice
- 🔢 Generates a random number from 1 to 6
- 🖱️ Interactive Roll Dice button
- ⚡ Updates the result dynamically
- 🎨 Simple and clean user interface

---

## ⚙️ How It Works

1. The user clicks the **Roll Dice** button.
2. JavaScript generates a random number between **1 and 6**.
3. The corresponding dice result is displayed on the webpage.
4. Every button click generates a new random result.

Example:

```text
Roll Dice
    ↓
Generate Random Number
    ↓
Number between 1 - 6
    ↓
Display Dice Result
```

## 💻 How to Run

2. Open `index.html`.

4. The application will open in your browser.

You can also open `index.html` directly in a browser.
